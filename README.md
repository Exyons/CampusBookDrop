# Campus Book Drop - A Book Exchange Project

## Overview

This project facilitates the buying and selling of used books among college students. It is built using the following technologies:

- **Express.js**: A web application framework for Node.js.
- **Node.js**: A JavaScript runtime for server-side development.
- **JavaScript**: The primary programming language for both client and server-side logic.
- **HTML**: Markup language for creating the structure of web pages.
- **CSS**: Styling language for designing the user interface.
- **MongoDB**: A NoSQL database for storing and managing data.
